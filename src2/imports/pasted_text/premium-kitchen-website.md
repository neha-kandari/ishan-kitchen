# MASTER PROMPT — PREMIUM CINEMATIC MODULAR KITCHEN WEBSITE

Create a premium, cinematic, multi-page website for a luxury modular kitchen design company.

Reference the visual sophistication, editorial composition, whitespace, large-scale imagery, material storytelling and premium architectural feel of:

https://magppie.com/

Do NOT copy the MAGPPIE brand, logo, text, images, product names, exact layouts or proprietary content.

Instead, create an ORIGINAL luxury kitchen brand with a similar level of elegance and sophistication.

The website should feel like:

**Luxury Interior Architecture + Premium Kitchen Design + Architectural Editorial + Cinematic Brand Experience**

It should NOT feel like a typical modular kitchen ecommerce website.

# CINEMATIC ANIMATION SYSTEM

The entire website should feel like one continuous visual story.

Use:

* Smooth page transitions
* Scroll-triggered reveals
* Image clip-path animations
* Text split animations
* Slow image scaling
* Horizontal scrolling galleries
* Parallax imagery
* Mask reveals
* Magnetic buttons
* Subtle cursor interactions

Animation should be slow and elegant.

Recommended easing:

cubic-bezier(0.16, 1, 0.3, 1)

Avoid:

* Bounce
* Elastic animations
* Excessive rotation
* Fast transitions
* Excessive blur
* Excessive parallax

# RESPONSIVE DESIGN

Desktop:

Large cinematic compositions.

Tablet:

Reduce animation complexity.

Mobile:

Use dedicated vertical hero video.

Navigation becomes minimal hamburger.

Large typography scales intelligently.

Images remain immersive.

Horizontal galleries become touch-scrollable.

Do not simply shrink the desktop layout.

Create an intentional mobile composition.

---

# PERFORMANCE

The website must remain highly performant despite its cinematic appearance.

Use:

Next.js

Tailwind CSS

Framer Motion

GSAP + ScrollTrigger where required

Lenis for smooth scrolling

Optimized MP4/WebM hero videos

WebP/AVIF images

Lazy loading

Responsive image sizes

Poster fallback for videos

Pause off-screen videos

Use transform/opacity animations.

Avoid unnecessary Three.js.

Use WebGL only where it materially improves the experience.

---

# ACCESSIBILITY

Maintain:

WCAG-compliant contrast.

Keyboard navigation.

Visible focus states.

Semantic headings.

Accessible buttons.

Reduced-motion mode.

Video fallback.

Meaningful image alt text.

Do not make the website dependent entirely on animation.

---

# IMPORTANT DESIGN RULE

The website should NOT look like:

"Kitchen Company + Navbar + Cards + Contact Form."

It should feel like a **luxury architectural brand experience**.

Every section should have breathing room.

Use fewer elements but make each element visually impactful.

Use oversized photography.

Use editorial typography.

Use asymmetrical layouts.

Use generous whitespace.

Use subtle transitions.

Use high-quality material imagery.

The visual hierarchy should always be:

1. Architecture
2. Kitchen
3. Materials
4. Brand story
5. Typography
6. Interaction
7. CTA
