Create a premium cinematic hero section for a luxury modular kitchen / interior design website.

IMPORTANT: Build the hero as an IMAGE-SEQUENCE-BASED SCROLL EXPERIENCE, not as a conventional static hero.

Use high-quality realistic architectural interior images sourced from Google image search / publicly available image references. The images must look like professional luxury interior photography.

## CORE CONCEPT

The hero tells one visual story through four sequential images:

1. EMPTY ROOM
2. PARTIALLY BUILT KITCHEN
3. ALMOST COMPLETE KITCHEN
4. FULLY COMPLETED LUXURY KITCHEN

The four images must have the SAME architectural space, SAME camera position, SAME perspective and approximately the SAME composition so that the transitions feel like one continuous cinematic transformation.

Do not use four unrelated kitchen images.

The sequence should visually communicate:

"An empty architectural space transforming into a beautifully designed kitchen."

## HERO STRUCTURE

Create a 400vh scroll section.

Inside it, create a 100vh sticky cinematic viewport.

The image sequence should remain pinned while the user scrolls.

Map scroll progress directly to the four images:

0–25% → EMPTY ROOM
25–50% → PARTIALLY BUILT KITCHEN
50–75% → ALMOST COMPLETE KITCHEN
75–100% → FINAL COMPLETED KITCHEN

Use smooth crossfades between the images.

Do not abruptly switch images.

Add subtle scale and camera-motion effects to make the sequence feel like a cinematic film.

## IMAGE SEARCH INSTRUCTIONS

When sourcing images, prioritize:

"luxury contemporary kitchen architecture interior"
"empty luxury residential kitchen interior"
"modern kitchen interior architectural photography"
"premium modular kitchen luxury interior"
"minimal warm contemporary kitchen interior"

IMPORTANT:

Do not select random images.

All four images must visually match in:

* camera angle
* room geometry
* floor
* windows
* wall architecture
* lighting direction
* perspective
* overall color temperature

If exact matching images cannot be found, prioritize creating a visually consistent sequence rather than using unrelated stock images.

## CINEMATIC TRANSITIONS

Use:

* crossfade
* subtle scale from 100% → 106%
* slight horizontal camera movement
* subtle depth/parallax
* gradual exposure change
* soft blur during image transitions
* smooth easing

The transition between images should feel like a cinematic architectural transformation.

Avoid:

* hard cuts
* flashy transitions
* zoom effects
* excessive parallax
* spinning
* bouncing
* generic website animations

## TYPOGRAPHY

Use elegant editorial typography.

Primary headline:

DESIGNED FOR LIVING

Use a sophisticated serif or high-end editorial font.

Supporting typography should use a clean modern sans-serif.

Typography should be:

* minimal
* spacious
* refined
* high contrast
* editorial
* premium

Keep text positioned in negative space so it never obstructs the kitchen.

## RESPONSIVE

Desktop:
Use full-screen 16:9 cinematic imagery.

Tablet:
Reduce parallax and preserve the central architectural composition.

Mobile:
Use portrait-oriented versions of the same four scenes while maintaining the same transformation story.

## DESIGN DIRECTION

The final result should feel like:

luxury architecture film
+
premium modular kitchen brand
+
editorial photography
+
cinematic storytelling

It should NOT feel like a SaaS landing page.

Do not add cards, gradients, excessive buttons, colorful UI, glassmorphism or unnecessary decorative elements.

The hero should be approximately 90% cinematic imagery and 10% interface.

MOST IMPORTANT:

The user should feel that they are scrolling through a short luxury architectural film where an empty room gradually transforms into a finished premium kitchen.

Make the scroll interaction smooth, slow, immersive and visually expensive.
